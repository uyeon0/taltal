# 제목 영역 다람쥐 크기

소개(`/intro`)와 시작 홈(`/`) 제목 영역의 다람쥐를 화면 폭에 맞춰 줄이고, 소개의 한 줄 설명에서 "3~5가지"를 뺀다. 지금은 두 화면 모두 150px로 고정이라 좁은 화면에서 제목이 세 줄로 꺾이고 제목 영역이 길어진다.

- 이슈: #32
- 기준 문서: `docs/requirements/onboarding.md`의 "소개", "시작 홈", 확인 기준, `docs/design.md`의 "다람쥐", "공간과 형태", `docs/tokens.css`
- 브랜치: `fix/header-mascot`. `origin/main`의 `7b90b59`에서 분기했다
- 휴대폰 확인은 사용자가 한다

## 사용자와 정한 것

| 항목 | 결정 |
| --- | --- |
| 크기 규칙 | `clamp(104px, 30vw, 150px)`. 화면이 좁으면 줄고, 500px 이상에서는 150px를 넘지 않는다 |
| 한 줄 설명 | `산 재료를 탈탈 털어 나눠 쓰는 요리를 알려 드려요.` "3~5가지"를 뺀다. 띄어쓰기는 기존 문구("나눠 쓰는", "알려 드려요")를 따른다 |

## 확인한 것

마우스가 있는 브라우저에서 같은 도메인 iframe을 360px, 390px 폭으로 띄우고, 소개 장의 좌우 안쪽 여백을 휴대폰 값(16px)으로 덮어 다람쥐 크기별로 쟀다. 실제 휴대폰은 보지 못했다. 표의 값은 제목 줄 수, 설명 줄 수, 제목 영역 높이다.

| 다람쥐 크기 | 소개 360px | 소개 390px | 시작 홈 360px | 시작 홈 390px |
| --- | --- | --- | --- | --- |
| 150(지금) | 3줄, 4줄, 260px. 360×640에서 문서 높이 653px | 3줄, 4줄, 260px | 3줄, 2줄, 208px | 2줄, 2줄, 181px |
| 114 | 2줄, 4줄, 224px. 문서 높이 640px | 2줄, 3줄, 198px | 2줄, 2줄, 172px | 2줄, 1줄, 146px |
| 108 | 2줄, 3줄, 198px. 문서 높이 640px | 2줄, 3줄, 198px | 2줄, 2줄, 172px | 2줄, 1줄, 146px |

새 한 줄 설명으로 같은 방법으로 쟀다. 크기는 선택한 규칙의 값(360px에서 108px, 390px에서 117px)이다.

| 문구 | 소개 360px | 소개 390px |
| --- | --- | --- |
| 새 문구(띄어쓰기 기존대로) | 설명 2줄, 제목 영역 172px, 360×640 문서 높이 640px | 설명 2줄, 제목 영역 172px |
| 붙여 쓴 형태("나눠쓰는", "알려드려요") | 3줄, 198px | 3줄, 198px |
| 지금 문구("3~5가지" 포함) | 3줄, 198px | 3줄, 198px |

붙여 쓴 형태는 줄바꿈 단위가 길어져 3줄이 되므로 띄어 쓴다.

소개 360px에서는 다람쥐가 114px 이하일 때 제목이 두 줄이 되고 360×640에 들어온다. 120px 이상에서는 달라지지 않았다. 선택한 규칙은 360px에서 108px, 390px에서 117px, 448px에서 134px다.

## 이 스펙에서 정한 것

사용자 확인이 필요한 항목이다.

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 값을 두는 곳 | `docs/tokens.css`와 `src/_app/styles/globals.css`의 `:root`에 `--mascot-header-size: clamp(6.5rem, 30vw, 9.375rem)`를 둔다 | 디자인 값 검사가 코드의 임의 값을 막고, 토큰은 두 파일이 같아야 한다(`tokens.test.ts`). 104px와 150px를 rem으로 쓴다. 이 프로젝트의 간격 토큰도 rem이다 |
| 적용 방법 | 두 화면의 `Mascot`에 `className="size-(--mascot-header-size)"`를 준다. `size` 프롭(150)은 그대로 둔다 | `next/image`가 폭과 높이를 요구하고, 이 값은 최대 크기이자 원본 비율을 알려 주는 용도로 남긴다. CSS의 `width`, `height`가 이 속성을 덮어쓴다. 컴포넌트는 고치지 않는다 |
| 다른 화면 | 계산 중, 추천 없음, 오류, 결과, 빈 목록의 다람쥐(200px, 112px 등)는 바꾸지 않는다 | 이슈 범위가 소개와 시작 홈의 제목 영역 다람쥐다 |

## 확인 방법

`npm run dev`로 띄우고 브라우저에서 확인한다. 마우스 환경이라 소개 장의 좌우 안쪽 여백이 휴대폰과 다르므로, 앞의 측정과 같이 iframe에서 여백을 16px로 덮어 쓴다.

- 360px, 390px, 448px, 500px 이상에서 다람쥐가 108, 117, 134, 150px로 나온다. 150px를 넘지 않는다.
- 소개 360×640에서 문서 높이가 640px 이하이고 시작 버튼과 점이 보인다. 제목이 "이 재료들을 / 어떻게 다 먹지?" 두 줄이고 설명이 두 줄이다.
- 공유 이미지(`/opengraph-image`)의 설명이 단어 중간에서 끊기지 않고 글자가 넘치지 않는다.
- 시작 홈 360×560에서 "직접 고르기"가 스크롤 없이 보인다.
- 제목과 다람쥐가 겹치지 않고 가로로 넘치지 않는다.

그 뒤 `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `fsd-review` 스킬로 점검한다.

## 문서 반영

구현 전에 문서를 먼저 고친다.

- `docs/requirements/onboarding.md`: 소개와 시작 홈의 다람쥐가 좁은 화면에서 줄고 넓은 화면에서 150px를 넘지 않는다는 항목과 확인 기준을 더한다.
- `docs/design.md`: "다람쥐"에 제목 영역 다람쥐의 크기 규칙을 더한다.
- `docs/tokens.css`: 위 토큰.
- `docs/copy.md`: "소개"의 설명 문구. `docs/overview.md`와 `docs/specs/app-foundation.md`에 인용한 문구도 같이 고친다.

물음표는 다람쥐 그림(`mascot.default`)에 들어 있어 따로 크기를 정하지 않는다.
