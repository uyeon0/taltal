# 소개 미리 보기

소개 캐러셀의 세 장에 비어 있던 미리 보기 영역을 채운다. 장마다 그 단계 화면의 핵심 요소를 앱 화면과 같은 모양으로 다시 그린 모형을 두고, 세 장이 두부 300g 예시 하나를 이어 쓴다.

- 이슈: #24 소개 미리 보기
- 기준 문서: `docs/requirements/onboarding.md`, `docs/copy.md`, `docs/design.md`, `docs/architecture.md`
- 브랜치: `feat/intro-preview`(`main`의 `628ca2d`에서 분기)

## 사용자와 정한 것

| 항목 | 결정 |
| --- | --- |
| 만드는 방식 | 실제 위젯을 줄이지 않고, 핵심 요소만 같은 모양으로 다시 그린 모형 |
| 예시 | 세 장이 두부 300g 예시를 이어 쓴다. 1장에는 대파 1단, 계란 5개를 함께 담는다 |
| 가상 예시 표시 | 두지 않는다 |
| 미리 보기 영역 | 감싸는 카드를 두지 않는다. 빈 카드는 공간을 채우려던 자리였다. 모형 자체를 장 제목 아래 남는 공간의 세로 가운데에 두고, 좌우 화살표도 모형의 세로 가운데에 맞춘다 |
| 제목 영역 아래 선 | 소개와 시작 홈의 제목 영역 아래에 앱 폭 전체 3px Ink 선을 둔다. 360×640 기준을 지키려고 제목 영역 아래 여백을 16px에서 12px로 줄인다. 시작 홈은 이슈 범위 밖이지만 같은 구조라 함께 바꾼다 |
| 시작 버튼 고정 영역 | 재료 입력의 아래 고정 영역처럼 위쪽에 3px Ink 선을 둔다. 디자인 보완(#22) 때 소개를 확인하지 않아 이 작업에서 맞춘다 |
| 장의 다람쥐 | 두지 않는다. 소개의 캐릭터는 제목 영역의 다람쥐가 맡는다 |
| 단계 라벨 | 보여 주지 않는다 |
| 캐러셀 비율 | 3:2를 유지한다. 마우스 환경의 좁은 창(390px 이하)에서는 3:2보다 길어지는 것을 허용한다 |

## 공간

휴대폰 360px 폭에서 캐러셀은 360×240이다. 장 제목이 두 줄이 되면 모형에 쓸 수 있는 높이는 142px이다. 모형은 이 높이에 들어가도록 실제 화면보다 촘촘하게 그린다. 구현 뒤 잰 모형 높이는 1장 104px, 2장 119px, 3장 112px이다.

마우스 환경에서는 캐러셀 화살표 자리로 슬라이드 좌우 여백이 48px이라, 창이 390px 이하이면 2장 요리 줄이 두 줄로 접혀 캐러셀이 3:2보다 길어진다. 이 경우는 허용한다.

## 장별 모형

공통:

- 미리 보기 영역에는 카드를 두지 않는다. 영역은 장 제목 아래 남는 공간을 채우고, 모형을 그 세로 가운데에 둔다. 캐러셀 화살표가 이 영역의 세로 가운데에 놓이므로 화살표와 모형의 가운데가 맞는다. 영역은 `aria-hidden`이고, 장의 문구(`h2`)가 뜻을 전한다.
- 모형은 실제 화면에서 주황 바탕 위에 놓인 모습 그대로다. 1·2장은 실제 화면처럼 Light 카드이고, 3장도 배분 표시는 Light 면 위에 놓는다는 규칙에 따라 Light 카드에 담는다.
- 글자는 14px 아래로 내리지 않는다. 재료 이름과 요리명은 16px, 양과 부가 글자는 14px이다.

1장 재료 입력: 담은 재료 목록

- 재료 줄 세 개(두부 300g, 대파 1단, 계란 5개)를 실제 목록처럼 Light 카드 하나에 담고 줄 사이를 1px Subtle 선으로 나눈다.
- 줄마다 재료 그림(24px), 이름, 오른쪽 끝의 양이다. 펼침 아이콘은 두지 않는다.

2장 추천 결과: 요리 묶음

- 요리 줄 세 개를 실제 요리 목록처럼 Light 카드 하나에 담고 줄 사이를 1px Subtle 선으로 나눈다.
- 줄마다 배분색 표식, "N번째 요리" 라벨 태그, 요리명, 쓰는 양("두부 150g")을 한 줄에 둔다. 조리 시간, 있으면 좋음, 필요한 양념은 두지 않는다.

3장 사용량과 남는 양: 재료 막대

- Light 카드 안에 둔다. 사용량 시트의 재료 한 줄을 펼친 모습이다.
- 제목 줄: 왼쪽에 "두부 300g", 오른쪽에 "20g 남아요". 사용량 시트의 재료 줄과 같은 배치다.
- 막대: 사용량 시트와 같은 모양(8px 라운딩, 3px Ink 선, 남는 양은 Light 빈 면)이고 높이만 16px로 낮다. 조각 폭은 `intro-example.ts`의 g 값으로 구한다.
- 막대 아래: 요리별 배분 내역(배분색 표식, 요리명, 양)을 줄바꿈되는 한 줄로 잇는다.

## 테스트

- `intro-carousel.test.tsx`: 미리 보기 세 개가 `aria-hidden`인지 보는 기존 확인을 유지한다. 장의 다람쥐가 빠졌으므로, 그림 확인은 모형의 재료 그림 대체 텍스트가 비어 있는지로 바꾼다.
- `intro-example.test.ts`: 요리별 g과 남는 g의 합이 처음 g과 같은지, 요리 수가 예시 문구와 같은지 확인한다.

## 확인 기준

- 세 장 모두 미리 보기에 모형이 있고, 단계 라벨, 가상 예시 표시, 장의 다람쥐가 없다.
- 휴대폰 360px, 390px 폭에서 캐러셀이 3:2이고 미리 보기 모형이 장 밖으로 넘치거나 잘리지 않는다.
- 1장 재료 줄, 2장 요리 줄, 3장 막대가 실제 화면과 같은 모양 규칙(라벨 태그, 배분색, 구분선, 막대 모양)을 따른다.
- 시작 버튼과 점 표시가 360×640 화면에서 함께 보인다. 시작 버튼 고정 영역 위쪽과 제목 영역 아래에 3px Ink 선이 있다.
- 시작 홈의 제목 영역 아래에도 같은 선이 있고, 360×560에서 "직접 고르기"가 스크롤 없이 보인다.
- lint, 타입 검사, 테스트가 통과하고 `fsd-review`에 새 위반이 없다.
