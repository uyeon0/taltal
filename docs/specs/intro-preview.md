# 소개 미리 보기

소개 캐러셀의 세 장에 비어 있던 미리 보기 영역을 채운다. 장마다 그 단계 화면의 핵심 요소를 앱 화면과 같은 모양으로 다시 그린 모형을 두고, 세 장이 두부 300g 가상 예시 하나를 이어 쓴다.

- 이슈: #24 소개 미리 보기
- 기준 문서: `docs/requirements/onboarding.md`, `docs/copy.md`, `docs/design.md`, `docs/architecture.md`
- 브랜치: `feat/intro-preview`(`main`의 `628ca2d`에서 분기)

## 사용자와 정한 것

| 항목 | 결정 |
| --- | --- |
| 만드는 방식 | 실제 위젯을 줄이지 않고, 핵심 요소만 같은 모양으로 다시 그린 모형 |
| 예시 | 세 장이 두부 300g 예시를 이어 쓴다. 1장에는 대파 1단, 계란 5개를 함께 담는다 |
| 가상 예시 표시 | 세 장 모두 모형 위 왼쪽에 작은 글자로 |
| 미리 보기 영역 | 감싸는 카드를 두지 않는다. 빈 카드는 공간을 채우려던 자리였다. 모형 자체를 주황 바탕 위에 둔다 |
| 단계 라벨 | 보여 주지 않는다. 요구사항에서 뺐다 |

## 공간

360px 폭(마우스 환경, 캐러셀 좌우 여백 48px)에서 잰 미리 보기 영역은 264×173px이다. 휴대폰은 좌우 여백이 16px이라 영역 폭이 328px 안팎이고 높이는 같다. 지금 이 영역을 빈 `Card`가 채우고 있다.

다람쥐(120px)가 영역 오른쪽 아래를 가로 72px, 세로 108px만큼 덮는다. 그림의 투명 여백까지 잰 값이다. 모형의 글자는 이 구역을 피한다. 모형 폭을 영역 폭에서 72px 뺀 만큼으로 줄여 다람쥐가 모형 옆 주황 바탕에 서게 하는 것을 기본으로 하고, 모형 모서리에 걸치게 할 수 있는지는 구현하면서 정한다.

| 위치 | 담는 것 |

## 장별 모형

공통:

- 미리 보기 영역에는 카드를 두지 않는다. 영역은 `aria-hidden`이고, 장의 문구(`h2`)가 뜻을 전한다.
- 모형은 실제 화면에서 주황 바탕 위에 놓인 모습 그대로다. 1·2장은 실제 화면처럼 Light 카드이고, 3장도 배분 표시는 Light 면 위에 놓는다는 규칙에 따라 Light 카드에 담는다.
- 모형 위 왼쪽에 "가상 예시"(`text-xs`)를 둔다. 주황 바탕 위라 Ink 글자다.
- 글자는 실제 화면보다 한 단계 작게 쓰되 14px 아래로 내리지 않는다. 재료 이름과 요리명은 16px, 양과 부가 글자는 14px이다.

1장 재료 입력: 담은 재료 목록

- 재료 줄 세 개(두부 300g, 대파 1단, 계란 5개)를 실제 목록처럼 Light 카드 하나에 담고 줄 사이를 1px Subtle 선으로 나눈다.
- 줄마다 재료 그림(28px), 이름, 오른쪽 끝의 양이다. 펼침 아이콘은 두지 않는다.

2장 추천 결과: 요리 묶음

- 요리 줄 세 개를 실제 요리 목록처럼 Light 카드 하나에 담고 줄 사이를 1px Subtle 선으로 나눈다. 줄마다 배분색 표식, "N번째 요리" 라벨 태그, 요리명, 쓰는 양("두부 150g")이다.
- 공간이 모자라면 요리명과 양을 한 줄에 둔다. 조리 시간, 있으면 좋음, 필요한 양념은 두지 않는다.

3장 사용량과 남는 양: 재료 막대

- Light 카드 안에 둔다. 사용량 시트의 재료 한 줄을 펼친 모습이다.
- 막대 제목 줄: "두부 300g".
- 막대: 사용량 시트와 같은 모양(높이 24px, 8px 라운딩, 3px Ink 선, 남는 양은 Light 빈 면). 조각 폭은 `intro-example.ts`의 g 값으로 구한다.
- 막대 아래: 요리별 배분 내역 세 줄(배분색 표식, 요리명, 양)과 "20g 남아요". 높이가 모자라면 내역을 한 줄에 "두부조림 150g · 두부찌개 100g · 두부전 30g"으로 이어 쓴다. 어느 쪽으로 할지는 구현하면서 화면에 맞춰 정한다.

## 문구

`docs/copy.md`는 이 작업에서 고쳤다. 코드의 `copy.intro`는 다음처럼 바꾼다.

| 지금 | 바꾼 뒤 |
| --- | --- |
| `exampleIngredient: '두부 300g'` | 1장 줄과 3장 제목에 쓰도록 재료와 양으로 나눈 예시 재료 목록. 두부 300g, 대파 1단, 계란 5개 |
| `exampleMeals: '두부조림 150g · 두부찌개 100g · 두부전 30g'` | 요리명과 양으로 나눈 예시 요리 목록 |
| `exampleLabel`, `exampleLeftover` | 그대로 쓴다 |
| `stepLabel` | 지운다 |

목록의 정확한 모양(배열, 객체)은 구현하면서 정한다. 화면에 보이는 글자는 `docs/copy.md`와 같아야 한다.

## 테스트

- `intro-carousel.test.tsx`: 미리 보기 세 개가 `aria-hidden`인지 보는 기존 확인을 유지한다. 장마다 "가상 예시"가 있는지 확인을 더한다.
- `intro-example.ts`: 요리별 g과 남는 g의 합이 처음 g과 같은지 확인한다.

## 확인 기준

- 세 장 모두 미리 보기에 가상 예시 표시와 모형이 있고, 단계 라벨이 없다.
- 360px, 390px 폭에서 미리 보기 모형이 영역 밖으로 넘치거나 잘리지 않고, 다람쥐가 글자를 가리지 않는다. 휴대폰 폭(좌우 여백 16px)과 마우스 환경(좌우 여백 48px)을 모두 본다.
- 1장 재료 줄, 2장 요리 줄, 3장 막대가 실제 화면과 같은 모양 규칙(라벨 태그, 배분색, 구분선, 막대 모양)을 따른다.
- 시작 버튼과 점 표시가 360×640 화면에서 함께 보인다.
- lint, 타입 검사, 테스트가 통과하고 `fsd-review`에 새 위반이 없다.
