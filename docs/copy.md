# 화면 문구

말투 규칙과 화면 문구를 정한다. 말투 규칙은 확정이고, 화면 문구는 초안이다. 구현하면서 화면에 맞게 문구를 바꿀 수 있지만, 말투 규칙은 지킨다.

코드는 문구를 한 파일에 모아 두고, 화면에 직접 쓰지 않는다. 서비스 이름은 탈탈(임시)이다.

표의 `{이름}`은 실행할 때 채우는 값이다. 재료 이름 뒤에 받침에 따라 달라지는 조사를 붙이지 않는다.

## 말투 규칙

해요체를 담백하게 쓴다. 재료 입력은 반복하는 일이라 감탄이 쌓이면 지치고, 실패 문구에 가벼운 말투는 맞지 않기 때문이다.

1. 사용자가 쓰는 말로 쓴다. 시스템이 쓰는 말은 바꾼다.
2. 숫자와 사실을 먼저 쓰고, 감탄하거나 칭찬하지 않는다. 느낌표와 이모지를 쓰지 않는다.
3. 버린 사람을 탓하지 않는다. "아까워요", "버리지 마세요"를 쓰지 않는다.
4. 안 되는 일은 이유와 다음 행동을 함께 쓴다. 넣은 재료가 유지되면 그렇다고 적는다.
5. 매일 요리한다고 가정하지 않는다. "오늘은", "내일은" 대신 순서로 말한다.
6. 언제 된다고 약속하지 않는다.
7. 1g 이상 남으면 "다 써요"라고 쓰지 않는다.
8. 다람쥐는 말하지 않는다. 문구는 서비스가 직접 말한다.
9. 순서를 강요하는 말("꼭", "반드시")을 쓰지 않는다.

| 쓰지 않는 말 | 쓰는 말 |
| --- | --- |
| 끼, 끼니 | 요리, N가지 요리 |
| 1일째, 2일째 | N번째 요리 |
| 조합 | 요리 N가지, 나눠 쓸 요리 |
| 보유량 | 가진 양 |
| 잔량 | 남는 양 |
| 소진 | 다 써요 |
| 일괄 담기 | 한 번에 담기 |

"묶음"은 화면에 거의 쓰지 않는다. 꼭 필요한 곳에서는 장 본 재료 묶음과 헷갈리지 않게 "요리 묶음"으로 쓴다.

## 공통

여러 화면이 함께 쓰는 조작의 이름이다. 아이콘만 있는 버튼이라 화면에는 보이지 않고, 화면 읽기 프로그램이 읽는다.

| 자리 | 문구 |
| --- | --- |
| 머리글 뒤로가기 버튼 | 뒤로 |
| 바텀시트 닫기 버튼 | 닫기 |
| 캐러셀 이전 장 버튼 | 이전 |
| 캐러셀 다음 장 버튼 | 다음 |
| 캐러셀 장 이동 점 | {n}번째 장으로 이동 |
| 캐러셀 장 이름 | {전체}장 중 {현재}번째 |

## 소개

| 자리 | 문구 |
| --- | --- |
| 제목 | 이 재료들을 어떻게 다 먹지? (화면에서는 "어떻게" 앞에서 줄을 바꾼다) |
| 설명 | 산 재료를 나눠 쓰는 요리 3~5가지를 알려 드려요. |
| 예시 재료 | 두부 300g |
| 예시 함께 담은 재료 | 대파 1단, 계란 5개 |
| 예시 요리 | 두부조림 150g · 두부찌개 100g · 두부전 30g |
| 예시 남는 양 | 20g 남아요 |
| 시작 버튼 | 내 재료로 시작하기 |
| 설명 1단계 | 가진 재료와 양을 넣어요. |
| 설명 2단계 | 재료를 나눠 쓸 요리를 확인해요. |
| 설명 3단계 | 어디에 얼마나 쓰고 남는지 봐요. |
| 캐러셀 이름 | 서비스 소개 |

미리 보기의 예시는 세 장이 이어 쓴다. 1장은 예시 재료와 예시 함께 담은 재료를 한 줄에 하나씩 쓴다. 2장은 예시 요리를 요리마다 한 줄로 나눠 요리명과 "두부 150g"처럼 쓰는 양을 쓰고, 순서는 요리 카드의 "{n}번째 요리"를 쓴다. 3장은 예시 재료를 막대 제목으로, 예시 요리를 배분 내역으로, 예시 남는 양을 막대 아래에 쓴다.

캐러셀 이름은 화면에 보이지 않고 화면 읽기 프로그램이 읽는다. 캐러셀의 이전, 다음, 장 이동 점, 장 이름은 "공통" 절에 있다.

## 시작 홈

| 자리 | 문구 |
| --- | --- |
| 제목 | 냉장고에 뭐가 있나요? (화면에서는 "뭐가" 앞에서 줄을 바꾼다) |
| 시작 안내 | 가진 재료부터 담아 주세요. |
| 주 행동 | 직접 고르기 |
| 예시 구역 제목 | 이렇게 나눠 쓸 수 있어요 |
| 예시 캐러셀 이름 | 예시 요리 묶음 |
| 따로 사는 재료 | 따로 사요: {재료} |

예시 캐러셀 이름은 화면에 보이지 않고 화면 읽기 프로그램이 읽는다. 가진 재료를 다 쓴다는 줄은 추천 결과의 "제목, 남는 재료가 없을 때"(가진 재료를 다 써요)를, 요리 순서는 "요리 카드"의 문구를 그대로 쓴다. 카드에 인분은 쓰지 않는다. 요리 순서는 화면에 번호만 보이고 화면 읽기 프로그램이 "N번째 요리"로 읽는다. 따로 사는 재료는 쉼표로 잇는다.

### 예시 묶음

가진 재료를 모두 다 쓰는 묶음만 둔다. 모두 각 요리 2인분이고 조금 사는 묶음이다. 양은 `formatAmount`로 쓴 값이다. 실제 레시피 데이터로 추천 함수를 돌린 결과를 옮겼고, 데이터가 바뀌어도 자동으로 바뀌지 않는다. 코드에서는 시작 홈에서만 쓰는 데이터라 `shared/copy`가 아니라 `src/_pages/home/model/samples.ts`에 둔다.

#### 1. 오징어·오이

| 자리 | 문구 |
| --- | --- |
| 재료 | 오징어 2마리 · 오이 2개 |
| 1번째 요리 | 오징어숙회: 오징어 1마리 |
| 2번째 요리 | 오징어도라지생채: 오징어 1마리 · 오이 1개 |
| 3번째 요리 | 오이나물: 오이 1개 |
| 따로 사요 | 대파, 도라지 |

#### 2. 돼지고기·계란

| 자리 | 문구 |
| --- | --- |
| 재료 | 돼지고기 500g · 계란 3개 |

| 2번째 요리 | 삼겹살깻잎전: 돼지고기 200g · 계란 1개 |
| 3번째 요리 | 계란말이: 계란 2개 |
| 따로 사요 | 대파, 깻잎 |

#### 3. 닭고기·계란

| 자리 | 문구 |
| --- | --- |
| 재료 | 닭고기 2마리 · 계란 3개 |
| 1번째 요리 | 닭강정: 닭고기 1마리 |
| 2번째 요리 | 닭꼬치구이: 닭고기 1마리 · 계란 1개 |
| 3번째 요리 | 계란말이: 계란 2개 |

### 요리 카드

| 자리 | 문구 |
| --- | --- |
| 순서 | {순서}번째 요리 |
| 순서 이유 | 빨리 상하는 {재료}부터 써요 |
| 조리 시간 | 조리 {시간} |
| 사야 하는 재료 | 따로 사야 해요: {재료와 양} |
| 있으면 좋은 재료 | 있으면 좋음: {재료} |
| 특수 양념 | 필요한 양념: {양념} |

순서 이유는 `urgency`가 "빨리 상함"일 때만 보여 준다. 순서 이유와 사야 하는 재료는 재료가 여럿이면 쉼표로 잇는다.
