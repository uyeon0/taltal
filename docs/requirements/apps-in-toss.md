# 앱인토스 미니앱

탈탈을 토스 앱 안의 미니앱(앱인토스 WebView 미니앱)으로도 제공하기 위한 요구사항을 정한다. 웹 서비스는 지금처럼 Vercel에서 운영하고, 같은 저장소에서 미니앱 번들을 따로 빌드한다.

화면, 문구, 추천 결과는 웹과 미니앱이 같다. 이 문서는 실행 환경 때문에 달라지는 부분만 정한다.

## 실행 환경

앱인토스 WebView 미니앱은 정적 번들(HTML, JS, CSS)을 토스 앱이 여는 방식이다. 화면을 그려 주는 서버가 없고 SSR을 지원하지 않는다. 그래서 미니앱 번들에는 SSR, `proxy.web.ts`, API 라우트가 들어가지 않는다.

| | 웹 | 미니앱 |
| --- | --- | --- |
| 결과물 | 서버에서 실행되는 Next.js 앱 | 정적 파일 묶음 |
| 올리는 곳 | Vercel | 앱인토스 콘솔 |
| 재료 목록 | 빌드할 때 페이지에 들어감 | 빌드할 때 번들에 들어감 |
| 레시피 | 같은 출처의 `/api/*` | Vercel의 `/api/*`를 다른 출처에서 호출 |

## 빌드

- 같은 소스에서 웹 빌드와 미니앱 빌드를 각각 만든다.
- 웹 빌드의 결과와 동작은 이 작업 전과 같다.
- 미니앱 빌드는 앱인토스 콘솔에 올릴 수 있는 번들을 만든다.

## 데이터

- 재료 목록은 웹과 같이 빌드할 때 화면에 넣는다. 재료 입력과 추천 결과가 쓰는 재료 목록은 웹에서도 정적 페이지에 들어가 브라우저로 내려가는 공개 데이터다.
- 레시피는 번들에 넣지 않는다. 후보 레시피, 레시피 상세, 레시피 이미지는 웹과 같이 Vercel의 API로 받는다. 서버가 레시피 전체를 브라우저로 보내지 않는다는 `docs/overview.md`의 규칙을 그대로 지킨다.
- 미니앱을 빌드할 때도 `data/app/`이 있어야 한다.

## API 접근

- API는 미니앱 주소에서 오는 요청을 CORS로 허용한다. 운영 주소 `https://<appName>.apps.tossmini.com`과 QR 테스트 주소 `https://<appName>.private-apps.tossmini.com`이다. 이 주소 형식은 SDK 3.1.1 이상 기준이다.
- 허용하는 출처는 이 두 주소와 웹 자신뿐이다. 다른 출처에는 열지 않는다.
- 미니앱은 API를 HTTPS로 호출한다.

## 첫 방문 판단

- 웹은 지금처럼 `proxy.web.ts`가 서버에서 쿠키를 보고 첫 방문이면 소개로 보낸다.
- 미니앱은 앱인토스 SDK의 `Storage`에 방문 시각을 저장하고 브라우저에서 판단한다. 웹과 같이 3일 안에 다시 오면 소개를 건너뛴다.
- 웹과 미니앱이 다르게 동작하는 곳은 이 판단 하나로 둔다. 화면 코드는 어느 환경인지 몰라도 동작해야 한다.

## 레시피 이미지 저장

- 이미지를 만드는 API(`POST /api/recipes/[id]/image`)는 웹과 미니앱이 같이 쓴다.
- 웹은 지금 방식으로 저장한다.
- 미니앱은 SDK의 `File.saveBase64`로 기기에 저장한다.

## 사용 기록 수집

Microsoft Clarity는 웹에서만 수집한다. 미니앱 번들에는 넣지 않는다.

## 범위

이번 범위는 미니앱 번들을 콘솔에 올리고 토스 앱에서 QR로 테스트하는 데까지다.

범위 밖:

- 검수 요청과 출시, 콘솔의 앱 정보 입력
- 광고. 넣을 때는 광고 API를 부르기 전에 `isSupported()`로 토스 환경인지 확인하고, 지원하지 않는 환경에서는 광고 영역을 그리지 않는다.
- 토스 로그인, 결제, 토스 전용 UI

## 확인 기준

- 웹 빌드로 배포한 서비스가 소개부터 레시피 이미지 저장까지 이 작업 전과 같이 동작한다. 첫 방문에 소개가 잠깐 보였다가 사라지지 않는다.
- 미니앱 빌드가 성공하고, 결과물에 서버 코드와 레시피 데이터가 들어 있지 않다.
- 토스 앱에서 QR로 연 미니앱이 소개부터 레시피 상세까지 동작한다.
- 미니앱에서 첫 방문에는 소개가, 3일 안에 다시 열면 시작 홈이 나온다.
- 미니앱에서 레시피 이미지를 저장하면 기기에 PNG가 저장된다.
- 허용하지 않은 출처에서 API를 호출하면 브라우저가 응답을 막는다.
- 미니앱 번들에 Clarity 스크립트가 없다.
