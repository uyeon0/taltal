디자인 보완 비교 시안

디자인 보완 후보(색 면, 모양, 글자, 그림)를 같은 화면에서 비교한다.

비교
화면
C-1, C-2에서 바꾼 것
  • 화면 배경 전체를 주황으로 두고 정보는 Light 카드에 담는다. 아래 고정 영역의 주요 버튼은 Ink 면, Light 카드 안의 주요 버튼은 Primary 면.
  • 카드 라운딩 12px → 20px. 하나 고르는 칩(수량, 인분, 가짓수)은 알약 모양.
  • 재료 행, 요리 카드처럼 같은 묶음의 행은 카드 하나에 담고 1px Subtle 선으로 나눈다.
  • 직접 입력, 재료 추가 같은 보조 행동은 상자를 빼고 Ghost로 둔다.
  • C-2는 요약 카드만 모서리를 사선으로 깎는다. 재료 입력 화면은 C-1과 같다.
T-1, T-2에서 바꾼 것
  • 요약: "다 써요", "남아요"를 라벨로 떼고 수치를 36px, 800으로 키운다. 두 덩어리 사이를 1px Subtle 선으로 나눈다.
  • T-1 라벨: 14px, 800, 자간 +8%. "N번째 요리", "다 써요/남아요", "있으면 좋음/필요한 양념"에 쓴다.
  • T-2 라벨: Ink 알약 태그. 요리 카드의 "있으면 좋음/필요한 양념"은 테두리만 있는 알약. 큰 제목 자간 -3%.
  • 재료 입력 화면은 T-2의 제목 자간만 다르다.
수치 크기 비교
  • 세 안 모두 T-1 라벨(14px, 800, 자간 +8%)을 쓰고 요약 수치 크기만 다르다.
요약 라벨 비교
  • 두 안 모두 요약 수치 24px, 700이고 라벨과 수치가 한 줄이다.
  • N-24P의 알약 태그는 Ink 면에 선이 없고 높이가 낮아, 3px 선과 44px 높이의 선택 칩과 모양이 다르다.
요리 라벨 비교
  • 세 안 모두 요약은 N-24P(알약 라벨, 수치 24px)다. 요리 카드 라벨만 다르다.
그림 비교
  • 세 안 모두 M-1(색·모양, 글자 결정 반영) 위에서 비교한다.
  • P-2의 다람쥐는 몸과 꼬리를 자르지 않고, 발만 카드 위쪽 선에 걸친다. 재료 입력 화면도 확인한다.
  • 재료 입력 화면은 실제 앱처럼 재료를 담은 뒤 제목 옆에 다람쥐가 없다. P-2의 재료 목록 위 다람쥐는 새로 더하는 그림이다.
